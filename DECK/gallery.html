DECK · ReconstructedBPY

OpenSCAD reconstructed as Blender Python

For each open-source OpenSCAD program, the harness renders canonical source views, has a generator agent produce readable bpy code, renders that revision from matched views, and sends both to an independent reviewer agent. Generation and review repeat until the reconstruction is accepted.
