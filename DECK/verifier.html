Why not standard 3D metrics?

Many valid outputs

An instruction like “make the treads overlap like leaves” has countless correct realizations. Distance to one reference output punishes all but one of them.

Edits are small and local

Image–text similarity barely moves when a slot is widened or a hole is added, and it cannot count parts or check how they connect.

Preservation matters

A correct edit that also wrecks the rest of the object should fail. Global scores cannot separate the two; a preservation item can.
