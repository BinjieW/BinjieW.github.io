DECK-Bench · Blender Python

Can a coding model edit a realistic 3D artifact?

DECK gives a model a readable, end-to-end Blender program and a natural-language edit. The edited program is executed, rendered from six views, and checked against an instruction-specific checklist. Edits range from changing one parameter to redesigning the object and composing a scene.

How a task works

The model sees only the program and the instruction. Everything else happens in Blender.

1 · Source program

A complete Blender Python program that builds the object from code, with reusable primitives and named semantic parameters.

2 · Edit instruction

One of six levels: a parameter, a component, several components, a structural change, a semantic redesign, or a scene.

3 · Execute & render

The edited program runs in Blender 5.1 and is rendered from six views next to the original.

4 · Checklist verdict

A multimodal verifier checks each item, including one that the rest of the object is preserved. The edit counts only if every item passes.

What we find

Editing realistic programs is hard, and difficulty climbs fast

The best model (GPT-6-astra) solves 65% of edits. Across models, the mean all-pass rate falls from 75% on single-parameter edits to 32% as soon as a component must change.

Results →

Open-weight models collapse beyond simple edits

Closed-source models average 41%, open-weight models 15%. From L4 on, open-weight models solve almost nothing.

Results →

Models fail by not making the edit, not by breaking the object

Of rendered edits that fail, 98% miss a requested change; only 2% fail solely because something unrelated broke.

Cases →

A VLM verifier agrees with humans on 87–92% of checklist items

Accuracy is lowest for structural edits (L4), where judging proportions and part relations from renders is hardest.

Verifier →

Critic feedback lifts models by 25–35 points

When a model critiques its own renders for a few rounds, all-pass rises from 53% to 78% (GPT-5.6-sol) and from 46% to 81% (GPT-5.6-terra). Most of the gain comes in the first three rounds.

What makes feedback work

Checklist-form feedback beats free-form feedback; a separate critic beats judging and revising in one call; a text-only model needs a vision-capable critic to improve.
