Editing Blender Python through compiled 3D artifacts.

DECK studies whether language models can modify executable programs whose correctness lives in the artifact they produce. Our first domain is Blender Python and editable 3D geometry.

Project components

A source-code corpus, a difficulty-graded benchmark, and an improvement loop.

The current work covers source-code preparation, controlled editing experiments, and iterative repair using different feedback.

01

Editable source corpus

A reconstruction harness turns open-source OpenSCAD programs into readable Blender Python through repeated generation by one agent, matched-view rendering, and independent review by another agent.

02

Difficulty-graded benchmark

A model edits an existing Blender Python program. Six levels cover parameter changes, component logic, topology, semantic restyling, and multi-object scene composition.

03

Feedback-driven recovery

We test whether render observations, checklist signals, and execution errors help the same model repair its own output over multiple rounds.

Benchmark procedure

From source program to scored edit.

Every model receives the same source and edit request. We run the revised program, render six fixed views, and use a VLM judge (Sonnet 5) to evaluate the checklist items.

Input Existing script

Reviewed bpy code produced by the source reconstruction harness.

Task Edit request

Four generated edits at each of six difficulty levels.

Model Code revision

The tested LLM returns a complete modified program.

Runtime Compile + render

Blender execution and six-view evidence generation.

Measure VLM judge (Sonnet 5)

Item-level checklist judgments from the rendered views.

Feedback-loop results

Current results from execution and quality feedback.

Blender error messages repair most initially non-rendering programs. The quality-feedback experiment compares six signals on the same Hardest-10 starting outputs.

84.77% → 99.77%

Render success after feeding Blender errors back to the original model. 396 of 402 initial failures were repaired, usually within 2–3 rounds.

+0.138

Largest aggregate quality gain: per-item checklist verdicts plus renders, across the nine models that support multimodal feedback.

Note on the current feedback setup

Checklist feedback and final scoring currently use the same benchmark rubric and VLM judge (Sonnet 5). A later experiment will separate the feedback and evaluation signals.
