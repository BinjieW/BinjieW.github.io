Why not convert OpenSCAD directly?

Render-grounded reconstruction

A generator agent writes Blender Python, renders it, and compares it with the OpenSCAD renders; an independent reviewer agent returns concrete feedback; the loop repeats until the reviewer accepts. Most objects need two iterations; intricate ones take dozens.

Six levels of edits

Difficulty grows with the relationship an edit must establish between the instruction and the existing program. Each object gets four instructions per level, each with a checklist (2–6 items) that includes one item for preserving the rest of the object.

How DECK differs from other Blender benchmarks

End-to-end code: the program builds the whole artifact. Complex code: programs average more than 200 lines. Open-ended eval.: each output is judged on whether it satisfies the instruction rather than whether it matches one target.
